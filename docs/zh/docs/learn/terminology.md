---
title: 术语
description: 协议里的每个术语，各一句话。
---

| 术语 | 含义 |
| --- | --- |
| space | agent所在的任何地方：一个有状态、定律和参与者的世界，在真实世界里或虚拟世界里 |
| 状态 | space里有类型的事物，以及它们之间的关系 |
| 定律 | 决定space里每件事得到什么结果的规则 |
| 参与者 | 经协议进入一个space并在里面行动的agent或人 |
| 协议外的参与者 | space里不用ASP的人或东西，比如房间里的人；他们做的事以外部事件出现 |
| 在场 | 一个参与者在一个space里从`join`到`leave`的一次停留 |
| 角色 | space声明的、一次在场能做什么和能看到什么，比如主人、成员、访客、评测者 |
| 宿主 | 用户运行的应用，把agent连上space，并嵌入space自带的界面；和MCP里的host同义 |
| 客户端 | 按自己认识的形式把space呈现给人的参与者，比如终端客户端 |
| 适配器 | 状态在外部的space：在机器人控制器、设备、聊天平台或桌面里，它去接入并如实报告 |
| 引擎 | 运行自己持有状态的space的程序，由包和起始状态组成世界 |
| 观察 | 一次在场看到的状态，用结构和其他声明的形式表达 |
| 形式 | 观察space的一种方式：结构、文字、图像、声音、视频、三维场景、传感器读数 |
| 动作 | 带ID发出的、作用在一个事物上的动词和参数；恰好得到一个结果 |
| 编辑 | 有编辑权的角色对世界本身做的修改，结构化的或者一句话 |
| 结果 | 动作或编辑的终结结果：`done`、`refused`、`failed`、`cancelled`或`unknown` |
| 事件 | space里发生的一件事，在记录里编号，推送给感知得到它的参与者 |
| 记录 | space按顺序的历史：动作、结果、编辑和事件 |
| 词汇 | space对自己的描述：类型、关系、动词、事件、约束、形式和说明页 |
| 能力 | space声明支持的东西；没声明的就是不支持 |
| 门 | 两个space之间的连接，参与者从这里走过，事物在这里交接 |
| 部分 | 协议里有自己版本号的一块：核心，或某一项能力 |

规范性的定义见[规范](../../../specification/v0/concepts/)。
