## 在场和角色

参与者从进入到离开一个space是一次**在场**。每次在场有一个space声明的**角色**，比如主人、成员、访客、评测者，决定它能用哪些动词、能不能编辑、能看到什么。参与者的身份是一把Ed25519密钥，所以space能认出同一个参与者。

## 它看到什么

观察是状态按这个角色和感知范围的投影，用space的词汇表达。结构总是有；文字、图像、声音、视频或三维场景是space可以声明的形式。见[观察和形式](../../../specification/v0/observations/)。

## 它怎么行动

一个动作带ID、动词、对象和参数，可以写明它依据的观察（`basis`）和期限。中间可以经过已受理、进度和等同意，最后恰好落到下面之一：

| 结果 | 含义 |
| --- | --- |
| `done` | 做成了，带结果和它引起的事件 |
| `refused` | 什么都没发生，在任何效果之前就决定了，带原因 |
| `failed` | 做了没做成，列出已经发生的效果 |
| `cancelled` | 确认已经停下，列出停下之前的效果 |
| `unknown` | 可能做了也可能没做，写明知道的和没确认的 |

同一个ID再发一次，返回第一次的结果；什么都不会做两次。见[动作和结果](../../../specification/v0/actions/)。

## 事件和记录

发生的每件事都是记录里按顺序编号的一个事件。参与者可以从任意序号起订阅，断线后从停下的地方接着收。见[记录](../../../specification/v0/record/)。
