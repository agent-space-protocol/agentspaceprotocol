---
title: space自带的界面
description: 给space一个任何宿主都能嵌入的界面，照MCP Apps做。
---

**状态：计划中。** 界面扩展写在`ext-views`仓库里，这个仓库还没公开；这一页讲它的设计。

形式是数据，界面是看数据和行动的方式。space可以自带界面，这是能力`views`：它声明一个或几个界面，每个是一个按内容哈希引用的网页包。宿主把网页包放进沙盒iframe里运行，界面只能经宿主、以宿主这次在场的身份观察和行动，看到的和能做的与这次在场完全相同。宿主不认识或不信任某个界面，就退回通用的结构视图。

这是照MCP Apps做的：MCP的工具声明一个`ui://`资源，宿主在沙盒iframe里渲染它。虚拟房间的三维画面就是这样一个界面：它属于房间，随房间一起发布，任何宿主都能显示。`ext-views`也提供网页组件`<agent-space>`，它连上一个space，以完整、只看或迷你模式显示它自带的界面或结构视图。
