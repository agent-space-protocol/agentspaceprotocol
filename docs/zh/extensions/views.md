**状态：计划中**，在`ext-views`仓库里。

| 部分 | 是什么 |
| --- | --- |
| 能力`views` | space列出自己的界面，每个是一个按内容哈希引用的网页包 |
| 消息`views` | 列出界面，按哈希取网页包 |
| 桥接 | 宿主怎么把观察和事件交给界面，再把界面的动作以宿主这次在场的身份发回去 |
| `<agent-space>` | 一个网页组件，连上一个space，以完整、只看或迷你模式显示它自带的界面或结构视图 |

界面能看到和能做的永远不会超过它所在的那次在场。宿主不信任某个界面时，改为显示结构视图。见[space自带的界面](../../docs/develop/views/)。
