---
title: Code of conduct
description: How we treat each other.
---

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1. Be respectful and constructive, assume good intent, and keep discussions about the work.

To report unacceptable behaviour, contact the maintainers privately through private reporting in the specification repository on GitHub. Reports are handled confidentially.
